## What is Wagashi Linux?

Wagashi Linux is an Arch-based Linux distribution built around a single idea:  
**your computer should feel like somewhere you actually want to be.**

Not a hacker tool. Not a rice showcase. Not a statement.  
A place. Calm, intentional, and quietly yours.

The technical foundation is Arch Linux — repositories, rolling release, AUR compatibility, the works.  
Everything else — the branding, the UX, the soul — is ours.

## Philosophy

**Technology with soul.**  
Software doesn't have to feel sterile to be powerful.  
Wagashi Linux believes the opposite: attention to emotional detail *is* a technical decision.

**Every old computer deserves a second life.**  
If it still turns on, it deserves a second chance.

**Intentionality over completeness.**  
We'd rather ship one thing that feels right than ten things that feel like filler.

**Nothing should make you feel stupid.**  
Not the installer. Not the error messages. Not the docs. Not the package manager.

---

## What Wagashi Linux is NOT

This list is as important as everything above.

- Not a hacker distro
- Not an "i use arch btw" statement
- Not a rice showcase for Reddit
- Not corporate, not sterile, not trying to look serious
- Not a meme OS (the humor is real, but it knows when to stop)

## The Yasashii Protocol

*Yasashii (優しい) — gentle, kind, soft.*

Yasashii is the communication layer of Wagashi Linux. It defines how the system talks to you.

Not what it does. How it speaks.

Every message the system produces — package manager output, error messages, installer prompts, system notifications, terminal feedback — follows the Yasashii Protocol. One consistent voice. One consistent feeling.

**The rules:**
- Be honest, never cold.
- Be brief, never curt.
- Be funny only when it's earned. Never performed.
- Never make the user feel stupid.
- Never make the user feel alone.

**Yasashii in practice:**

```
✦ Syncing repositories... (the internet is cooperating today)
✦ Resolving dependencies... hang tight.
✦ All done. Your computer is slightly better now.
```

```
✦ Couldn't find that package. Maybe it doesn't exist, maybe it's you.
```

```
✦ Something went wrong. Not your fault — probably.
  Check the log at /var/log/wagashi/dango.log
```

The Yasashii Protocol is not a personality. It's a commitment.  
Every tool, every script, every message in Wagashi Linux follows it.  
If it doesn't feel Yasashii, it's not done yet.

## Human Defaults

Wagashi Linux ships with sane defaults chosen to reduce friction, not maximize configuration.  
The system should feel comfortable immediately after installation.

- Fonts are chosen, not inherited accidentally.
- Animations are subtle and purposeful.
- Audio levels are reasonable.
- Power management respects old hardware.
- The desktop should feel calm before customization.

Customization matters. But comfort comes first.

Wagashi Linux believes that choosing Linux shouldn't mean leaving your life behind.

The goal is **first-class Windows application support** — not as an afterthought, not as a "it might work" footnote, but as a core part of the experience. Wagashi Linux will ship with Wine deeply integrated, configured, and tuned out of the box.

## `dango` — the package manager

`dango` is not just a pacman wrapper. It's a complete package management suite.  
One command. One voice. Every source.

```
sudo dango -S firefox       # installs from pacman or AUR — dango decides
sudo dango -R firefox       # removes a package
sudo dango -Syu             # updates everything, including AUR
sudo dango -Ss firefox      # searches pacman + AUR simultaneously
```

Under the hood it orchestrates `pacman`, `libalpm`, and `yay` for AUR.  
On the surface it's ours — one consistent voice, one consistent experience.

**What dango supports:**
- Arch official repositories
- AUR (via yay, managed internally)
- Wagashi own repository

**What dango does not support:**
- Flatpak. Intentionally. No exceptions.

The messages are human. The errors are honest. The humor is earned.

## Hikaru — the installer

*From Sora no Hikaru — Clannad OST. "Light of the sky."*

Hikaru is the Wagashi Linux installer. It guides you in. It doesn't lecture you.

Every prompt follows the Yasashii Protocol. Every step feels intentional.  
The goal: someone who has never installed Linux before finishes the installation and thinks *"that wasn't scary at all."*

**Hikaru ships in two forms:**

**Hikaru CLI** — terminal installer with a Wagashi-native voice and Yasashii messaging.  
Fully centered, carefully paced, coral where it matters. Used in Mishio and Nayuki.

**Hikaru GUI** — graphical installer built from scratch with Wagashi's visual identity.  
Soft, calm, guided. Not a wizard full of checkboxes — a conversation.  
Detects the active edition automatically and loads the corresponding palette.  
Used in Ayu, Sayuri, and Nayuki.

Both follow the same principle: installation should feel like arriving somewhere, not surviving something.

## Ushio — virtualization

*Ushio lives inside Wagashi Linux.*

Ushio is Wagashi Linux's virtualization layer — QEMU-KVM configured, tuned, and ready to use.  
Not "install virt-manager and good luck." Ready. Out of the box.

Ushio is optional at install time. When you choose it, it sets everything up:  
GPU passthrough, network configuration, all of it. No documentation required.
